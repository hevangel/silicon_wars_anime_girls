# Silicon Wars gallery

The gallery previews the Compute Triad reference cards, the rendered Pilot 001 page, and its rough storyboard. Build it from the repository root, then open the printed HTML file in a browser.

```sh
python tools/build_site.py site-preview
```

Use `py` in place of `python` if that is how Python is installed on Windows. The output directory contains the complete static preview.
