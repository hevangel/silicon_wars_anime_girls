# Silicon Wars gallery

The gallery previews the Compute Triad references and the chapter 1 storyboard. Build it from the repository root, then open the printed HTML file in a browser.

```sh
python tools/build_site.py site-preview
```

Use `py` in place of `python` if that is how Python is installed on Windows. The output directory contains the complete static preview. For deployment, publish the generated directory as the site root.
