# Remotion renderer (issue #82)

Install dependencies using `npm install` in this folder, then run `npm run studio` or `npm run render`. This project uses Remotion 4.x and React, 720 frames at 24fps and 1920×1080. No narration media is supplied. A reproducible dependency lockfile and an actual render must be produced and tested before release; package installation/render was not executable in the current authoring environment.
