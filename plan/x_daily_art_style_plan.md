# Daily X Art Style Posting Plan

Daily posting schedule featuring one art style per day across **Microsoft**, **ARM**, **TSMC**, and **Broadcom**.

## Posting Rules & Template

- **Skill to Use:** Always use [skills/post-image-to-x](../skills/post-image-to-x/SKILL.md) (`.\skills\post-image-to-x\scripts\post_image.ps1`) with all 4 character images passed to `-ImagePath`.
- **Publish Reminder:** Make sure to **click the Post button** (do not stop at draft/preview or pass `-DryRun`), verify the published `https://x.com/.../status/...` URL, and close the `playwright-cli` session afterward so `%USERPROFILE%\.playwright-x-profile` is unlocked for the next day.
- **Cadence:** 1 style per day (4 images per post: Microsoft, ARM, TSMC, Broadcom).
- **Required Hashtag:** Always include `#what_if_ai_companies_are_anime_girls` on every X post from this repo.
- **Suggested Post Copy:**
  `Day [N]: [Style Name] — Microsoft, ARM, TSMC & Broadcom #what_if_ai_companies_are_anime_girls`
- **Coverage:** 22 styles exist across all 4 characters in `website/artwork/`. (`doa-era-3d` exists for Microsoft, ARM, and Broadcom, but not TSMC, so it is omitted from the 4-character rotation.)
- **Progress:** 1 / 22 posted.
