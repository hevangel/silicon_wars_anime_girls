# Layouts

[Single-panel layout](single-panel.yaml) frames one splash panel (1640 × 2050, 4:5) on the same 1800 × 2600 page, as used by Pilot 001 page 002.

[4:3 single-panel layout](single-panel-4x3.yaml) frames one landscape panel (2000 × 1500) on a 2080 × 1560 page, as used by Pilot 004.

[Six-panel RTL layout](six-panel-rtl.yaml) gives reusable pixel geometry for an 1800 × 2600 page. The origin is the upper-left corner. Read paired rows right to left, then move down the page. The two panoramic panels are framed independently of the four middle panels.
