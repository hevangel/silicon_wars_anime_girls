# Fairchild Semiconductor — The Silicon Matriarch

> An original *Silicon Wars* company-personification character. Unofficial fictional fan work.

| Field | Design |
|---|---|
| Faction | Grandmother Generation |
| Age portrayal | elder |
| Hair color | white |
| Brand color motif | red |

## Appearance
Very elderly formidable grandmother with white hair, scarlet polka-dot bandana and rolled sleeves

## Clothing and equipment
Vintage semiconductor workshop shirt, round spectacles, wafer tray and practical tools

## Personality
Pragmatic, bossy, protective and inventive

## Speech patterns
Commands the noisy children like an experienced forewoman

## Thinking and values
Manufacturable silicon and entrepreneurship make new empires

## Motivation
Preserve the early Silicon Valley family

## Dramatic flaws
Bitter about descendants receiving all the fame

## Rivalries
Texas Instruments and Motorola

## Alliances
Intel, AMD and startup descendants

## Special ability
**Planar Genesis** — a fictional metaphor for the real technology.

## Signature line
> Intel! AMD! Stop fighting at my table!
