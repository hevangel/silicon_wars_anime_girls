# Working on Silicon Wars

- Read the [series bible](bible/story_bible.md) and the relevant profiles in the [roster](characters/INDEX.md) before editing a chapter.
- Keep character identity, scene state, and lettering separate. Preserve stable panel IDs and record accepted generation inputs beside the render.
- Use a branch and show before/after art in the pull request. Compare reading order, costume continuity, and lettering at the intended reading size.
- Treat the original posters under scratchpad/originals/ as archival files. Save new assets under the appropriate character or chapter folder.
- Scope dependency changes to the requested submodules. Record the upstream revision when changing a pin.
