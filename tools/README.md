# Tools

- `render_pilot.py` validates the [pilot](../chapters/pilot-001/README.md), prints individual generation prompts, and assembles lettered pages from panel PNGs. It defaults to the page-001 plan; pass `--plan chapters/pilot-001/render-page-002.yaml` for the single-panel page 002. Install Pillow 10.1+ and PyYAML.
- `build_site.py` packages the [website](../website/index.html) (HTML, CSS, JS, and JSON data) with the reference cards and character, expression, and chibi sheets it lists into a new output directory using Python 3.9+ and the standard library.
- `update_market_caps.py` refreshes Yahoo Finance market-cap snapshots in `website/data/characters.json`. Install its optional dependency with `python -m pip install -r tools/requirements-market-cap.txt`, then run `python tools/update_market_caps.py`. Use `--dry-run` to preview, or `--symbols INTC NVDA` to update selected configured tickers. Failed quotes retain their last successful value and timestamp; the script exits with status 1 if any fetch fails. Successful updates are written atomically.

Reference-card sorting reads each character's `sort` object: `curatedOrder` (ascending), `foundedYear` (oldest first), and `marketCapUsd` (largest first). Name sorting uses the existing `name`. Curated order is the default; sorting controls appear only on the Reference Cards archive, and the front page remains a carousel. Missing market caps sort last, with curated order breaking ties.

Browsing groups are tags stored in each character's `groups` array. A character can appear under several groups, and the dropdown is built from these arrays. The separate `faction` field describes the story faction shown in character profiles. Foundry and equipment tags share Foundry Guild; AI Academy includes its junior labs; semiconductor companies share Silicon Kingdoms while retaining tags such as Memory Kingdom or Foundry Guild.

Market-cap snapshots include the original currency and amount, the USD conversion rate and its date, Yahoo's market timestamp when available, a fetch timestamp, and the Yahoo quote URL. Non-USD listings use the last available Yahoo `CCYUSD=X` closing rate over five days; the updater caches each rate during a run. For unlisted startups, `marketCapUsd` holds an estimate from the latest disclosed funding valuation or acquisition price. `marketCapBasis` distinguishes public market caps, funding valuations, and acquisition prices; `valuationEstimate` records the source amount/currency, event date, deal status, source URL, and any USD conversion. Disclosed lower bounds are marked `greater_than`; pending acquisitions are marked as pending. Private estimates are researched manually and preserved by the Yahoo updater, which skips entries without a ticker. Parent-company market caps are excluded. Historical organizations and other companies without a substantiated valuation remain null. Set `sort.yahooSymbol` when a company begins trading. Samsung's founding year refers to Samsung Electronics (1969); Broadcom's refers to Broadcom Inc.'s HP semiconductor lineage (1961).

The updater uses [yfinance](https://ranaroussi.github.io/yfinance/reference/api/yfinance.Ticker.get_info.html) to access Yahoo Finance. Run its offline checks with `python -m unittest discover -s tools -p test_update_market_caps.py`.
- `make_character_template_layouts.py` redraws the blank model sheet, expression sheet, and reference card layout guides in [characters/_template/layout/](../characters/_template/layout/). Install Pillow 10.1+.

To refresh a private-company estimate, search for the most recent disclosed funding round or acquisition, update `sort.valuationEstimate` and the derived USD `sort.marketCapUsd`, and record the verification time in `sort.marketCapUpdatedAt`. Prefer company announcements and filings; record deal status instead of treating an announced acquisition or an IPO target as a completed transaction.
